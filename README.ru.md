# LowKeyboard

[English](README.md) · **Русский**

Лёгкая многоязычная экранная клавиатура (IME) для Android 4.0.4 – 7.1 (API 15–25).
Только чистая Java и Android SDK: без сторонних библиотек, без разрешения `INTERNET`,
всё, что вы вводите, остаётся на устройстве.

## Возможности

- **24 раскладки из коробки**
  - Кириллица: русский, украинский, белорусский, болгарский, сербский
  - Греческий
  - Латиница: английский, немецкий, французский, испанский, португальский, итальянский,
    польский, чешский, турецкий, шведский/финский, норвежский/датский, румынский, венгерский,
    индонезийский, вьетнамский
  - Письмо справа налево: арабский, иврит, персидский
- **Разумные значения по умолчанию** – английский и язык системы; клавиатура стартует с языка
  системы. Набор следует за языком системы, пока вы сами не выберете языки
  (кнопка в настройках возвращает значения по умолчанию).
- **Переключение языков** клавишей с глобусом по кругу между включёнными языками. Если включён
  один язык, клавиша скрыта. На пробеле показано название текущего языка. Последний
  выбранный язык запоминается.
- **Долгое нажатие на пробел** открывает системный выбор клавиатуры.
- **Долгое нажатие на букву** показывает варианты с диакритикой (`a` → `à á â ä …`, `е` → `ё`, …).
  Долгое нажатие на `.` / `,` / `-` даёт больше знаков препинания, удержание Delete повторяет
  удаление.
- **Цифровой ряд** – по умолчанию всегда на виду. Можно показывать его только на символьной
  раскладке (тогда цифры видны маленькими подсказками на верхнем ряду букв, долгое нажатие
  вводит цифру). В этом режиме высота клавиатуры не меняется, а символы делятся на две
  страницы (`=\<` / `?123`).
- **Темы**: Holo, Material Light, Material Dark, MIUI 5, Flyme, TouchWiz.
- **Звук нажатий** – системный звук клавиатуры, можно отключить.
- **Высота клавиш** – ползунок (30–60 dp).
- **Клавиша Enter** подстраивается под действие поля: лупа (поиск), стрелка (далее/перейти),
  галочка (готово).
- Shift с Caps Lock (двойное нажатие) и автоматическая заглавная буква в начале предложения.
- **Скрытие значка приложения** на рабочем столе (настройки остаются доступны в
  *Настройки → Язык и ввод → LowKeyboard*).
- Вся клавиатура рисуется на одном `Canvas`, раскладки и темы хранятся в коде, поэтому APK
  остаётся маленьким.

### Чего нет

Нет подсказок, автозамены и словарей, менеджера буфера обмена и панели эмодзи, а также языков,
которым нужен составной ввод (китайский, японский, корейский), и сложных письменностей
(хинди, тайский и др.).

## Установка

1. Установите APK (`adb install app-release.apk` или откройте файл на устройстве).
2. Откройте **LowKeyboard**, нажмите **1. Включить клавиатуру**, затем **2. Выбрать клавиатуру**.
3. Выберите языки, тему и высоту клавиш в приложении.

Настройки применяются при следующем показе клавиатуры.

### Встраивание в системный образ (предустановленное приложение)

- Положите APK в `/system/app/LowKeyboard/LowKeyboard.apk` (права `644`).
- Клавиатура объявляет подтип `en_US` (клавиатура), чтобы система считала её обычным IME;
  по умолчанию она предлагает английский и текущий язык системы.
- Чтобы сделать её клавиатурой по умолчанию, задайте её в настройках метода ввода по умолчанию
  вашей прошивки.

> Поведение на конкретной прошивке (автоматическое включение, выбор по умолчанию) зависит от
> версии Android и ROM, его нужно проверить на целевом устройстве.

## Сборка

Требования: JDK 17+ и Android SDK (compileSdk 34).

```
./gradlew assembleRelease
```

APK появится в `app/build/outputs/apk/release/`.

- `minSdk 15`, `targetSdk 25`, исходный уровень Java 8, зависимостей нет.
- Релизная сборка использует R8 (`minifyEnabled`, `shrinkResources`) и оставляет только строковые
  ресурсы `en` и `ru` (`resConfigs`).
- Релизная сборка подписывается **отладочным ключом**, чтобы её можно было сразу установить.
  Перед распространением замените `signingConfig` в `app/build.gradle` на свой ключ.
- Проверка lint `ExpiredTargetSdkVersion` отключена, так как `targetSdk 25` выбран намеренно.

## Структура проекта

```
app/src/main/java/com/m929/lowkeyboard/
  KbService.java       сервис метода ввода (InputConnection, действия поля, автозаглавная)
  KbView.java          клавиатура: раскладка, отрисовка, обработка касаний, всплывающие окна
  Layouts.java         все раскладки и символы по долгому нажатию (генерируется, см. tools/)
  Theme.java           цветовые схемы и размеры
  GlobeIcon.java       значок глобуса в виде команд Path (генерируется из SVG, см. tools/)
  SettingsActivity.java  экран настроек
tools/
  gen_layouts.py       генерирует Layouts.java
  svg2java.py          переводит SVG-контур глобуса в GlobeIcon.java
```

### Как добавить язык

Отредактируйте таблицу в начале `tools/gen_layouts.py` (код, название, три ряда букв, символы
по долгому нажатию, дополнительные знаки) и сгенерируйте файл заново:

```
python3 tools/gen_layouts.py app/src/main/java/com/m929/lowkeyboard/Layouts.java
```

### Как добавить тему

Добавьте запись в `Theme.ALL` и название в `Theme.NAMES` в файле `Theme.java`.

## Хранение настроек

Настройки лежат в файле SharedPreferences `kb`: `mask2` (включённые языки), `lang2`
(текущий язык), `theme`, `keyH` (высота клавиш, dp), `digSym` (цифровой ряд только на символах),
`sound` (звук нажатий).

### Версия 1.1: что исправлено и добавлено с помощью ассистента SourceCraft

- **Раскладки справа налево** (арабская, иврит, фарси) зеркалятся: первый символ ряда стоит у правого
  края, как на системной клавиатуре (`Layouts.RTL`, `KbView.addRow`).
- **Удаление** идёт через `InputConnection` (`deleteSurroundingText`, выделение заменяется) с откатом на
  обычные key events — работает в WebView и в полях с composing text.
- **Автоматическая заглавная буква** пересчитывается при перемещении курсора (`onUpdateSelection`).
- **Высота клавиш** из настроек ограничивается диапазоном 30–60 dp, поэтому устаревшее или испорченное
  значение больше не даёт непригодную клавиатуру.
- **Текущий язык** записывается обратно в настройки, если сохранённый язык выключен.
- **Отложенные задачи** (долгое нажатие, повтор удаления) отменяются при отсоединении вью, поэтому
  «фантомное» удаление больше не продолжается после скрытия клавиатуры.
- **Подпись Send** переведена (`enter_send`) и ужимается по ширине клавиши.
- **Панель вариантов** не становится шире экрана, а символы в узких ячейках уменьшаются.
- **Экран настроек** переписан на нативный `PreferenceActivity` с категориями; темы и языки —
  чекбоксы (тема всегда одна, языков остаётся хотя бы один).
- **Настройка звука нажатий**: используется системный звук клавиатуры, аудиофайлов в APK нет.
- **Тема TouchWiz**: подложка `#747678`, клавиши букв `#E1E1E1`, чёрный текст, пробел и системные
  клавиши `#A8A7AA` (клавиша Enter рисуется тем же цветом).

Ассистент не компилировал и не запускал код: сборку и проверку на устройстве выполнял автор.
